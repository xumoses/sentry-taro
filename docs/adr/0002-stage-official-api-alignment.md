# 分阶段对齐官方 Sentry API

统一包的公共 API 以官方 Sentry JavaScript SDK 为方向。第一阶段在保留核心行为的前提下完成薄封装、统一导出和简单调用优化；涉及 Replay 状态、缓冲投递、生命周期或 React 接入行为的系统性对齐放在第二阶段。

这一安排让首次合并及本地候选包验收能够先完成，同时避免把现有接口全部固化为长期公开约定。只有名称和语义都一致的接口才说明为已对齐；小程序特有能力和暂未对齐项明确列出，必要的兼容入口保留。

第二阶段按目标自托管服务的官方支持范围选择 SDK 大版本，并采用该支持线的最新稳定版本作为验证候选。正式支持承诺以目标服务端到端验证通过的能力为准，暂不同时维护面向更新服务的功能支持分支；这使公共 API 承诺与实际可用能力一致，代价是部分上游新能力暂不提供支持。具体基线、平台边界及验证要求见[设计原则](../design-principles.md)。

默认行为同样以固定官方版本为起点。只有具体平台限制或实际测量证明需要时，才采用有说明、可配置且有回归验证的平台差异；现有 POC 的缓冲窗口和会话上限不作为长期默认值。工具链迁移先行，SDK 版本、公共 API 和运行时默认值的实现及验收另行记录在[第二阶段进度](../implementation/phase-two.md)。
