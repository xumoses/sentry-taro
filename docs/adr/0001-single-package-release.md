# 统一发布监控与 Taro Replay

将现有监控 SDK 与 Taro Replay 合并到 `sentry-taro`，后续仅发布 `@xumoses/sentry-taro`。相比继续分别维护两个发布单元，选择共同发布并将后续修复集中到新包；错误监控可独立使用，Replay 仍显式开启。

旧包不再接受修复，后续通过 npm deprecate 指向新包。第一阶段保留既有行为并完成首个验证项目的本地候选包验收，较大重构及公网发布留到第二阶段。

第一阶段候选版本使用 `0.1.0-beta.1`，保留产物与源码校验记录。正式版本及 npm 标签在第二阶段发布前决定，不承诺直接稳定发布。beta 期间允许附有迁移说明的必要接口调整，旧包在新包发布及正式迁移验收通过后弃用。

2026-10-14 补充决策：第一阶段以首个验证项目的本地候选 tarball 接入、微信开发者工具及真实 Sentry 错误接收、Replay 关联和 Playback 验证为集成门槛，不要求公网发布。npm 发布、正式依赖与锁文件切换、发布包 CI 以及旧包 deprecate 移至第二阶段发布工作；体验版及真机验收在第二阶段重构完成后进行，以 iOS 为准，Android 后续补充。
