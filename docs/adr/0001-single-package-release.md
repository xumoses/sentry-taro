# 统一发布监控与 Taro Replay

将现有监控 SDK 与 Taro Replay 合并到 `sentry-taro`，后续仅发布 `@xumoses/sentry-taro`。相比继续分别维护两个发布单元，选择共同发布并将后续修复集中到新包；错误监控可独立使用，Replay 仍显式开启。

旧包不再接受修复，后续通过 npm deprecate 指向新包。第一阶段保留既有行为并完成首个项目迁移验收，较大重构留到第二阶段。

首版使用 `0.1.0-beta.1` 与 npm `beta` 标签，在第二阶段 API 收敛后再发布稳定版。beta 期间允许附有迁移说明的必要接口调整，旧包在首个项目迁移验收通过后弃用。
